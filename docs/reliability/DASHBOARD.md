# Reliability Dashboard Requirements

## System

Show overall reliability, active P0/P1 incidents, TAT breaches, production availability, current deployment, and last-known-good state.

## Agents

Show normalized error rate, workload volume, resolution rate, recurrence rate, regression rate, average TTR, verification failure rate, and escalation rate.

## Workflows

Show CI, Runtime E2E, deployment, security, integration, and other workflow health with drill-down to incidents.

## Intelligence

Show recurring Failure DNA, root-cause clusters, permanent-fix score, emerging regressions, and technical-debt candidates.

## Headroom

Show model/task usage, routing distribution, retry counts, blocked loops, estimated savings, and high-cost task categories.

## CTO

Show recent CTO digests, decisions, vetoes, escalations, pending approvals, and unresolved disagreements.
